# 使用指南

界面为「顶栏 + 左侧项目树 + 右侧内容区」：顶栏「视频文本中心」菜单可切换视频文本、测试用例与词汇表三个页面；左侧树管理项目（新建、重命名、删除）。

## 1. 创建项目与添加视频

1. 左侧项目树点「新建」，输入项目名称。
2. 右上角「添加视频」，粘贴哔哩哔哩视频网址；支持多行批量粘贴。
3. 选择「视频类型」：
   - **直播连麦**：下载后做讲述人采样与说话人分离；
   - **个人录屏**：跳过说话人分离，更快更准；
   - 多分P视频会先探测分P清单，勾选后逐P添加。

## 2. 下载与转写

- 每行视频有「查看 / 编辑 / 删除」三个入口，「编辑」抽屉的「基础」页签里有**下载音频**、**转写文本**与**一键转写**（下载完成后自动衔接转写）。
- 表格自带展开箭头，展开即可查看转写文本与音频播放器；转写进度显示在状态列。
- 长音频自动分块并行转写；片头广告或精华片段可在「设置」页签配置**截断开头**（转写起点，单位秒）。
- 转写完成后可导出 txt / srt / json / 洗稿文本（「文本」页签右上按钮）。

## 3. 讲述人校准（多人视频推荐）

1. 下载完成后，系统自动对音频做声纹采样（后台进行，不阻塞转写）。
2. 状态列出现红点提示「请确认讲述人」；打开「编辑」抽屉的「校准讲述人」页签。
3. 逐条**试听**样本，在输入框写下真实姓名（已保存的名字会自动回显），点**确认讲述人**。
4. 重新转写后，系统以这些声纹为聚类种子，纠正整段视频的讲述人归属。

## 4. 词汇表

语音模型不支持热词，词汇表以两种方式生效：带**误识别词**的词条在文本展示时自动替换；仅带说明的词条作为人工修复的参考。

- **全局词汇表**（顶栏菜单进入）：左侧分类、右侧词条表格，均支持增删改；全局词条跨视频生效。
- **视频级词汇表**（编辑抽屉「词汇表」页签）：继承展示全局词条（标「系统」，只读），可添加本视频专属词条；全局已有的词条不允许重复添加。
- 误识别词支持多变体，用 `|` 分隔，例如 `work bud|work body`。
- 替换按「误识别词最长优先」执行，避免短变体破坏长变体匹配。

## 5. 文本查看与洗稿

- 「文本」页签内是音频播放器与**原始文本 / 洗稿文本**两个子页签。
- 每个段落带讲述人标签（点击改名）、时间戳（点击跳转音频对应位置）与段落 hash。
- 洗稿文本支持逐段手动修订（「编辑」按钮），修订带「已编辑」标记并可恢复默认；洗稿只在单段落内做句子去重，不会误删开场白。
- 「自动分章」按固定段落数生成章节（可改名、删除、手动添加）。

## 6. 测试用例与测试组

- 测试用例页左侧为**测试组**树，右侧为用例表格（内部滚动、底部翻页）。
- 每个用例配置一个时间段（开始秒数 + 截取时长 + 说话人数），执行后给出「使用前（无截断 / 无词汇表）」与「使用后（按配置）」两份转写文档对照，用于验证词汇表与截断是否生效。
- 测试组把多个时间段的用例整合，左侧组条目上可**运行整组**，按顺序逐个执行。
- 用例执行完可人工判定「通过 / 失败」，沉淀为回归资产。

## 7. 推荐工作流

```text
新建项目 → 批量添加视频 → 一键转写 → 试听并校准讲述人 → 重新转写
        → 积累全局/视频词汇表 → 重新转写 → 修订洗稿 → 分章 → 导出
```

遇到识别不准的词，先加词汇表（全局级优先，便于跨视频复用），再用测试用例验证替换效果。
