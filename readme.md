# open-video

把哔哩哔哩视频转成文本的本地管理系统。创建项目、批量添加视频，点一下按钮即可自动下载音频并用本地语音模型转写为文本——全程本地运行，不依赖任何在线语音服务。

## 功能特性

- **本地语音转写**：基于 SenseVoice int8 模型（sherpa-onnx），识别质量好、速度快（约 60 倍实时速率），数据不出本机。
- **说话人分离与校准**：多人对话自动区分说话人；下载后自动采样声纹，试听命名确认后，重新转写即按声纹纠正全片归属。
- **长音频并行加速**：自动分块（默认 300 秒 + 20 秒接缝）并行转写，两小时播客约十几分钟完成。
- **结构化转写文档**：输出带段落 hash、讲述人、时间戳的标签化文档；原始文本与洗稿文本一一对应，支持手动修订。
- **两级词汇表**：全局词汇表按分类管理、跨视频生效；视频级词汇表继承全局词条（只读），并可添加本视频专属词条；误识别词自动替换。
- **章节与导出**：自动分章（可改名/删除），段落级时间轴点击跳转播放；导出 txt / srt / json / 洗稿文本。
- **测试用例与测试组**：用「使用前 / 使用后」对照验证词汇表与截断配置的效果；测试组把多个时间段的音频整合验证。

## 快速开始

```bash
pnpm install             # 安装依赖（需要 Node.js 22.5+ 与 pnpm 8+）
pnpm run setup:bin       # 下载 yt-dlp 与 ffmpeg 到仓库内部 bin 目录
pnpm run setup:model     # 下载语音识别、VAD 与说话人分离模型到 models 目录
pnpm run build           # 构建前端
pnpm start               # 启动服务，默认 http://127.0.0.1:3000
```

首次启动会在 `data/` 下自动创建 sqlite 数据库；音频、模型与个人数据均不入版本库。

开发模式：`pnpm run dev` 同时启动后端与前端热更新。

详细说明见文档：

- [使用指南](docs/guide/usage.md)

